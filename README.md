# SketchList

A native macOS app for planning DJ sets. Metadata-only — organize your music library, build setlists and playlists, save transitions, and get Camelot-based recommendations for what to mix next.

## About

SketchList is a planning tool for DJs, not a mixing tool. It doesn't play or store audio files; it works with track metadata (title, artist, BPM, key) so you can browse, search, and arrange your library visually. Actual mixing happens in your existing DJ software.

## Status

Early development. Not yet distributed. Currently building out v1 core features: library management, setlist/playlist/transition CRUD, and Camelot-based transition recommendations.

## Requirements

- macOS 15 (Sequoia) or later
